LOOTIFER V17 — PRODUCT PRESENTATION + COLLECTIONS HUB

Wijzigingen:
- Productdetail: geen zichtbare fotokaders meer. Uitgesneden productfoto's zweven rechtstreeks op de donkere pagina.
- Miniaturen: geen donkere hokjes meer; alleen de foto. De gele selectie-ring zit strak om de foto.
- Admin Producten: de niet-functionele knop “Bestaande foto's zoeken” is verwijderd.
- Admin blijft werken met “Kies fotomap” en “Kies 1-4 foto's”; JPG/JPEG/PNG/WebP worden automatisch verwerkt en gekoppeld.
- Collecties in de hoofdnavigatie opent nu collections.html.
- Nieuwe eigen Collecties-pagina: 6 collectiewerelden + 6 highlights = 12 tegels direct in één overzicht op desktop.
- De 6 highlights gebruiken dezelfde instellingen als Admin > Homepage.
- Taalwissel NL/EN blijft werken.

Start:
1. npm install (alleen nodig als node_modules ontbreekt)
2. npm start
3. Open index.html met Live Server.
4. Gebruik localhost voor Admin en API.

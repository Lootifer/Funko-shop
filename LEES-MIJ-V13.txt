2nd Life Toys - COMPLETE V13
====================================

Dit is een complete projectmap, geen losse update.

BELANGRIJKSTE AANPASSINGEN
- Website start standaard in het Engels en in de lichte weergave.
- Bezoekers kunnen daarna zelf Nederlands/Engels en licht/donker kiezen; hun keuze blijft bewaard.
- Producten kunnen vanuit Admin > Producten permanent worden verwijderd.
- Bestellingen kunnen vanuit Admin > Bestellingen permanent worden verwijderd.
- Bij het verwijderen van een bestelling wordt de voorraad automatisch hersteld wanneer dat nog niet eerder is gebeurd.
- Tekst in het Funko-submenu en de keuzelijsten is beter leesbaar.
- De knop terug naar de winkelwagen heeft nu duidelijk contrast.
- De winkelpagina heeft een nieuw overzicht met categorieën, universums, Funko-lijnen, zoeken en voorraadkeuze.
- De titel Filters/Filteren heeft een duidelijke kleur.
- De bestaande winkelpagina's voor alle categorieën en Funko-subcategorieën zijn behouden.

INSTALLEREN / OPENEN
1. Pak de ZIP volledig uit.
2. Open de uitgepakte map Funko-shop in Visual Studio Code.
3. Open de terminal in die map.
4. Voer uit: npm install
5. Voer daarna uit: npm start
6. Open index.html met Live Server.

LET OP
- Verwijderen in Admin is definitief en vraagt daarom eerst om bevestiging.
- Test de website lokaal voordat je deze versie naar GitHub pusht.
- node_modules is bewust niet in de ZIP opgenomen; npm install maakt die map opnieuw aan.
